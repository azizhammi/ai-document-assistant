
# AI Document Assistant

A Python application that allows users to
ask questions about PDF documents and receive
answers supported by document references.

## Planned Features

- PDF text extraction
- Semantic search with embeddings
- AI-generated answers
- Page-level source references
- Automated tests

## Technology Stack

- Python
- FastAPI
- PyMuPDF
- Sentence Transformers
- Pytest

## Project Status

Milestone 1: Initial backend setup.
